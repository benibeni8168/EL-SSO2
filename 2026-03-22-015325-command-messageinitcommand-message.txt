     Bulk User Import — Investigation & Implementation Plan

     Context

     The user wants Keycloak to support bulk importing of users (e.g., from a
     CSV file or JSON array). This is useful when migrating users from another
     system or setting up a new realm with many users at once.

     ---
     Finding: Partial Support Already Exists

     Keycloak already has a Partial Import feature (POST 
     /admin/realms/{realm}/partialImport) that can bulk-import users from a JSON
      file in the Keycloak realm export format. A full UI for this lives in
     Realm Settings → Partial Import.

     What's missing for a good bulk user import experience

     ┐

     │
     ├──────────────┼───────────────────────────────────────────────────────────
     ┤
     │ Location     │ Partial Import is in Realm Settings, not in the Users
     │
     │              │ section — not discoverable
     │
     ├──────────────┼───────────────────────────────────────────────────────────
     ┤
     │ Format       │ Only accepts Keycloak realm JSON format, not CSV (which
     │
     │              │ is what most people export from spreadsheets)
     │
     ├──────────────┼───────────────────────────────────────────────────────────
     ┤

     The PartialImportRealmRepresentation body format is:
     {
       "users": [ /* array of UserRepresentation */ ],
       "ifResourceExists": "SKIP" | "OVERWRITE" | "FAIL"
     }

     ---
     Implementation Plan: Bulk Import Users Modal

     Frontend-only — No backend changes required

     1. Create js/apps/admin-ui/src/user/BulkImportUsersModal.tsx (new file)

     PatternFly Modal with:
     - Format toggle: "CSV" / "JSON" (Radio buttons or Tabs)
     - File upload area using existing FileUpload PatternFly component (drag &
     drop + click)
     - Collision policy dropdown: "Skip existing" (SKIP) / "Overwrite existing"
     (OVERWRITE) / "Fail on conflict" (FAIL)
     - Template download link: a small helper that generates a sample CSV for
     the user to fill in
     - Import button → on submit:
       - For CSV: parse rows → build UserRepresentation[] → wrap as { users, 
     ifResourceExists } → call adminClient.realms.partialImport()
       - For JSON: parse JSON array of user objects → same wrapping → same call
     - Results display: After successful call, show summary: "X added, Y
     skipped, Z failed"
     - Error handling: Show alert for parse errors and API errors

     CSV format (first row = header):
     username,email,firstName,lastName,enabled,emailVerified,password,temporary,
     groups,realmRoles
     john.doe,john@example.com,John,Doe,true,true,Password1!,true,/admins;/users
     ,admin;viewer
     - groups and realmRoles — multiple values separated by semicolons
     - password — if provided, creates a CredentialRepresentation with
     type=password
     - temporary — sets credential.temporary (default: true if omitted)
     - All fields except username are optional
